# 🛍️ Customer Shopping Behaviour Analysis

## 📌 Project Overview
An end-to-end data analytics project exploring customer shopping behaviour using Python, SQL, and Power BI.

## 🛠️ Tools Used
- **Python:** Data loading and exploratory data analysis
- **Pandas:** Data manipulation and analysis
- **SQL:** Business analysis and querying
- **Power BI:** Interactive dashboards and data visualization

## 🔄 Project Workflow
1. Loaded the customer shopping dataset using Python and Pandas.
2. Performed exploratory data analysis to understand the dataset.
3. Used SQL queries to analyze customer shopping behaviour and answer business questions.
4. Developed an interactive Power BI dashboard to visualize the findings.
